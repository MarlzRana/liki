# The value bar

A point is **worth a card** only if *all three* hold. This single definition governs
both `low-value` (an existing card below it) and `uncovered` (a point above it that no
card tests) — so both reviewers judge "worth a card" identically.

- **central** — a core mechanism, tradeoff, or contrast the page is actually *about*; not
  an incidental aside, and not an example's specific numbers.
- **non-obvious** — someone already knowledgeable in the domain couldn't trivially
  re-derive it or already know it cold. Excludes the definition of a term the owner
  plainly knows, and anything recomputable on the spot.
- **durable** — a lasting concept, not an ephemeral detail (a version number, a current
  CLI flag, a today-only benchmark figure, present pricing). Those rot.

**Priority** for what a worthwhile card tests: core **mechanism** (how/why) → key
**tradeoff / failure mode** (when it stops helping, what it costs) → an important
**contrast** with a related idea. Include a formula only when the formula *is* the
relationship being tested.

Value is deliberately **not** weighted by current work-relevance — only centrality,
non-obviousness, and longevity.
